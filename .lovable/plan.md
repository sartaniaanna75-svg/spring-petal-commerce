# Тюльпаны в Москве — магазин + мини-админка

Лёгкий, весенний, романтичный сайт продажи тюльпанов с доставкой по Москве. Уход от «сеточного» шаблона интернет-магазина: редакционная вёрстка, крупная типографика, асимметричные блоки, мягкая анимация лепестков и пастельные акварельные тона.

## Визуальный язык
- Палитра: тёплый кремовый фон, пудрово-розовый, свежая зелень стебля, глубокий бордово-тюльпановый акцент.
- Типографика: контрастная пара — изящный дисплейный шрифт для заголовков + спокойный гротеск для текста.
- Приёмы: крупные фото-полосы, «сорванные» края секций, лёгкие тени, скругления, ненавязчивое появление при скролле. Никаких трёхколоночных «фич» и стоковых бейджей.

## Публичная часть

Хедер (сквозной)
- Логотип-леттеринг, навигация (Каталог, Доставка, О нас), телефон/мессенджер, счётчик корзины.
- Прилипающий, компактный при скролле; мобильное меню.

Главная (/)
- Крупный герой с фотографией и оффером «Свежие тюльпаны с доставкой по Москве сегодня».
- Блок «Букеты недели» — 3–4 карточки в асимметричной раскладке.
- Полоса «Как это работает»: срез — сборка — доставка за 2 часа.
- Сорта/цвета тюльпанов горизонтальной лентой.
- Отзывы и мягкий CTA-блок с формой быстрой заявки (имя + телефон).

Каталог (/catalog)
- Фильтры: цвет, количество стеблей, цена; сортировка.
- Карточки товара: фото, название, кол-во стеблей, цена, быстрое «в корзину».

Карточка товара (/catalog/$slug)
- Галерея, описание, состав букета, цена, выбор количества, кнопка в корзину, условия доставки, похожие букеты.

Корзина + оформление (/cart)
- Список позиций с изменением количества и удалением, сумма, стоимость доставки.
- Форма заказа: имя, телефон, адрес/район Москвы, дата и интервал доставки, комментарий, согласие с офертой и политикой. Валидация zod.
- Экран «заявка принята» с номером заказа.

Доставка (/delivery) — зоны и сроки по Москве, стоимость, самовывоз, оплата.

Политика конфиденциальности (/privacy) и Оферта (/offer) — текстовые страницы.

Футер — контакты, ссылки на разделы и правовые страницы, соцсети, реквизиты.

## Админка (/admin)
- Вход по email/паролю, доступ только для роли admin.
- Заявки: список заказов с составом, контактами, датой доставки; смена статуса (новая / в работе / доставлена / отменена).
- Товары: создание, редактирование, скрытие/публикация, загрузка фото, цена, кол-во стеблей, цвет, описание.

## Техническая часть
- Lovable Cloud: таблицы `products`, `orders`, `order_items`, `user_roles` (+ функция `has_role`), storage-бакет для фото букетов.
- RLS: публичное чтение только опубликованных товаров; вставка заказа доступна анониму; чтение/изменение заказов и запись товаров — только admin. GRANT'ы для anon/authenticated/service_role.
- Роут-структура TanStack Start: `index`, `catalog`, `catalog.$slug`, `cart`, `delivery`, `privacy`, `offer`, `admin` (+ вложенные `admin/orders`, `admin/products`), у каждой страницы собственные head-метаданные для SEO.
- Корзина — локальное состояние (localStorage), заказ уходит в базу через server function с валидацией.
- Дизайн-токены в `src/styles.css`, компоненты на shadcn с кастомными вариантами.
- Стартовые демо-букеты добавляются миграцией, чтобы каталог не был пустым.
