# Полноценная админ-панель магазина

Цель: удобный вход, сводка по бизнесу, полное управление заявками и ассортиментом, галерея до 5 фото на товар с загрузкой с компьютера.

## 1. Вход в админку

- На странице входа `/auth` добавить восстановление пароля (письмо со ссылкой) и отдельную страницу «Новый пароль».
- Сбросить пароль существующему администратору `admin@admin.com` и сообщить новый — чтобы вход заработал сразу.
- В шапке сайта добавить ссылку «Панель управления», видимую только администратору, чтобы не искать адрес вручную.

## 2. Дашборд (новая стартовая страница админки)

Плитки за сегодня / 7 дней / 30 дней:
- количество заявок и сумма выручки;
- новые (необработанные) заявки;
- средний чек;
- топ-5 товаров по продажам;
- список последних 5 заявок со ссылкой на раздел «Заявки».

Разделы админки: Сводка · Заявки · Товары.

## 3. Заявки

- Поиск по номеру заказа, имени и телефону.
- Фильтр по дате (сегодня / неделя / месяц / произвольный период) в дополнение к фильтру по статусу.
- Раскрывающаяся карточка заявки: состав, упаковка, пожелания, адрес, дата и слот доставки, комментарий, сумма.
- Кнопка «Позвонить» (tel:) и копирование телефона/адреса в один клик.
- Внутренняя заметка менеджера к заявке (сохраняется в базе).
- Удаление заявки с подтверждением.
- Выгрузка отфильтрованного списка в CSV.

## 4. Товары

- Поиск по названию, фильтр по типу (штучно / букеты / композиции) и по «скрыт / опубликован».
- Быстрый переключатель «показывать в каталоге» прямо в списке, без открытия формы.
- Дублирование товара (создать копию как основу для нового).
- Ручной порядок вывода в каталоге (поле сортировки, кнопки вверх/вниз).
- Форма редактирования сохраняет все поля: название, ссылку, цену, количество стеблей, цвет, тип, описание, состав, публикацию.
- Галерея до 5 фото: загрузка с компьютера (выбор файла или перетаскивание), превью, выбор главного фото, удаление, изменение порядка. Главное фото используется в каталоге, вся галерея — в карточке товара на сайте.

## 5. Карточка товара на сайте

Если у товара несколько фото — показывать галерею с миниатюрами и переключением.

## Техническая часть

- Миграции: `products.images jsonb` (массив путей, до 5) + `products.sort_order int`, `orders.admin_note text`; политики доступа остаются админскими.
- Загрузка файлов — существующий приватный бакет `product-photos`, ссылки формируются как сейчас (подписанные URL).
- Новые серверные функции в `src/lib/admin.functions.ts`: `getDashboardStats`, `deleteOrder`, `setOrderNote`, `duplicateProduct`, `reorderProducts`; все под `requireSupabaseAuth` + проверкой роли администратора.
- Новые маршруты: `_authenticated/admin.index.tsx` — сводка, `admin.orders.tsx` — заявки, `admin.products.tsx` — товары (расширяется).
- Публичное чтение галереи — через существующие публичные функции каталога.
