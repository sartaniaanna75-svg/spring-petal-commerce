# Blooming Moscow

Собери сайт для продажи тюльпанов в городе Москва - (распиши структуру подробнее: не забудь - основная панель, каталог, карточка товара, корзина, хедер, футер, доставка, политика конфиденциальности и оферта) + небольшую админку, куда будут уходить заявки и можно будет добавлять и редактировать товары. Стиль легкий, весенний, романтичный, при этом уйди от стандартного шаблона интернет-магазина.
